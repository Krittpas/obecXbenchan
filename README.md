# OBEC × BENCHAN ESPORTS 2569 · ROV TOURNAMENT 2026

เว็บไซต์ทางการของ **การแข่งขันกีฬาอีสปอร์ต (ROV TOURNAMENT 2026)**
ในการแข่งขันกีฬานักเรียน นักศึกษาและประชาชน ชิงชนะเลิศแห่งจังหวัดจันทบุรี ประจำปี 2569
จัดโดย **สมาคมกีฬาแห่งจังหวัดจันทบุรี** ร่วมกับ **โรงเรียนเบญจมราชูทิศ จังหวัดจันทบุรี**

แข่งขัน **วันเดียวจบ** 9 กันยายน 2569 เวลา **07:30–16:30 น.** ณ **หอประชุมชินวรประทานวิทยาสิทธิ์**
แบ่งเป็น **รุ่น ม.ต้น 16 ทีม** และ **รุ่น ม.ปลาย 13 ทีม**
แข่งแบบ **แพ้คัดออก (Knockout) ทุกรอบ** ตั้งแต่รอบแรกจนถึงรอบชิงชนะเลิศ ทุกแมตช์เป็น **Bo3**

สร้างด้วย **Next.js 16 (App Router) + TypeScript + Supabase** พร้อม deploy บน **Vercel**

จุดสำคัญ: **เว็บทำงานได้ทันทีแม้ยังไม่ได้ตั้งค่า Supabase** โดยจะอ่านข้อมูลจริงชุดเดียวกันจาก `lib/fallback.ts`
เมื่อใส่ environment variables ครบแล้ว ทุกหน้าจะสลับไปดึงจากฐานข้อมูลโดยอัตโนมัติ

### ฝั่งเจ้าหน้าที่ (`/admin`)
- เข้าสู่ระบบด้วย Supabase Auth และต้องมี `user_id` อยู่ในตาราง `admins`
- **คุมผลสดหน้างาน** — แก้คะแนน/สถานะแล้วหน้าผู้ชมอัปเดตทันที (ถ้าตั้งเป็น “จบแล้ว” โดยไม่เลือกผู้ชนะ ระบบตัดสินจากคะแนนให้)

## ขั้นตอนติดตั้ง

### 1. ติดตั้งและรันในเครื่อง

```bash
npm install
cp .env.example .env.local   # แล้วแก้ค่าตามข้อ 2
npm run dev                  # http://localhost:3000
```

### 2. ตั้งค่า Supabase

1. สร้างโปรเจกต์ที่ [supabase.com](https://supabase.com)
2. ไปที่ **SQL Editor** แล้วรันไฟล์ตามลำดับ (รันซ้ำได้ทั้งสองไฟล์)
   - `supabase/migrations/0001_init.sql` — ตาราง, คอลัมน์รุ่น/ครู/ระดับชั้น, RLS, Realtime
   - `supabase/migrations/0002_real_data.sql` — ข้อมูลจริง 29 ทีม พร้อมรายชื่อนักกีฬาและผังสายทั้งสองรุ่น
3. ไปที่ **Project Settings → API** แล้วคัดลอกค่าลง `.env.local`

```env
NEXT_PUBLIC_SUPABASE_URL="https://xxxx.supabase.co"
NEXT_PUBLIC_SUPABASE_ANON_KEY="eyJhbGciOi..."
SUPABASE_SERVICE_ROLE_KEY="eyJhbGciOi..."
NEXT_PUBLIC_SITE_URL="https://ชื่อโปรเจกต์.vercel.app"
REVALIDATE_SECRET="สุ่มข้อความยาว ๆ"
```

> `SUPABASE_SERVICE_ROLE_KEY` ใช้ฝั่งเซิร์ฟเวอร์เท่านั้น **ห้าม**ใส่ `NEXT_PUBLIC_` นำหน้าเด็ดขาด

### 3. สร้างบัญชีผู้ดูแล

1. Supabase → **Authentication → Users → Add user** (ใส่อีเมลและรหัสผ่าน, ติ๊ก auto confirm)
2. คัดลอก `User UID` แล้วรันใน SQL Editor

```sql
insert into public.admins (user_id, email)
values ('วาง-user-uid-ที่นี่', 'อีเมลผู้ดูแล');
```

3. เข้าสู่ระบบที่ `/admin/login`

### 4. Deploy บน Vercel

```bash
git init
git add .
git commit -m "OBEC x BENCHAN Esports website"
git branch -M main
git remote add origin https://github.com/<user>/<repo>.git
git push -u origin main
```

จากนั้นที่ [vercel.com/new](https://vercel.com/new) → Import repo → ใส่ Environment Variables ทั้ง 5 ตัวข้างบน → Deploy
(ตั้ง region เป็น `sin1` ให้แล้วใน `vercel.json` เพื่อความเร็วในไทย)

หลัง deploy ครั้งแรก อย่าลืมแก้ `NEXT_PUBLIC_SITE_URL` ให้เป็นโดเมนจริงแล้ว redeploy

## การอัปเดตข้อมูลระหว่างงาน

หน้าเว็บใช้ ISR (cache 15–60 วินาทีแล้วแต่หน้า) และล้าง cache ให้อัตโนมัติทุกครั้งที่บันทึกจากแผงผู้ดูแล
หน้า `/live` ไม่ต้องรอ cache เพราะรับข้อมูลผ่าน Supabase Realtime โดยตรง

ถ้าแก้ข้อมูลจาก Supabase Dashboard โดยตรง สามารถสั่งล้าง cache ได้ที่

```bash
curl -X POST "https://โดเมนของคุณ/api/revalidate?secret=REVALIDATE_SECRET"
```

หรือผูกกับ **Database Webhooks** ของ Supabase ให้ยิงอัตโนมัติเมื่อข้อมูลเปลี่ยน

```
  types.ts                    ชนิดข้อมูลตรงกับตารางใน Supabase

  fallback.ts                 ข้อมูลจริงชุดสำรอง ใช้เมื่อยังไม่ต่อฐานข้อมูล
  admin-schema.ts             นิยามฟอร์มและ whitelist ตารางของแผงผู้ดูแล

```

ทีมที่ส่งใบสมัครแต่ไม่ปรากฏในผังสายถือว่าถูกตัดสิทธิ์ และไม่ถูกนำขึ้นเว็บ

**รูปแบบการแข่งขัน** — แพ้คัดออก (Knockout) ทุกรอบ Bo3 ตั้งแต่รอบแรกจนถึงรอบชิงชนะเลิศ

หากผังสายหรือรายชื่อเปลี่ยน ให้แก้ผ่านแผงผู้ดูแลที่ `/admin` ซึ่งเป็นแหล่งข้อมูลจริงหลังต่อ Supabase แล้ว

**หมายเหตุด้านข้อมูลส่วนบุคคล** — เว็บแสดงเฉพาะชื่อทีม ชื่อนักกีฬา ระดับชั้น และชื่อครูผู้ควบคุม
ไม่แสดงอีเมลและเบอร์โทรศัพท์ที่อยู่ในใบสมัคร

## การถ่ายทอดสด

เข้าแผงผู้ดูแล `/admin/settings` → หัวข้อ **การถ่ายทอดสด**

1. วาง **ลิงก์ถ่ายทอดสด** — รองรับ YouTube (`watch?v=`, `youtu.be/`, `live/`), Facebook Live และ Twitch
   ระบบแปลงเป็นวิดีโอฝังให้เอง ไม่ต้องหาโค้ด embed
2. ติ๊ก **กำลังถ่ายทอดสดอยู่ขณะนี้** เพื่อให้ขึ้นป้ายแดง ON AIR บนหน้า `/watch`
3. กด **บันทึกการตั้งค่า** หน้าเว็บอัปเดตทันที

ถ้ายังไม่ใส่ลิงก์ หน้า `/watch` จะแสดงข้อความรอถ่ายทอดสดพร้อมปุ่มไปหน้าผลสดและกำหนดการแทน

## รูปภาพในเว็บไซต์

ทุกจุดรับเป็น **ลิงก์รูป (URL)** ไม่ต้องแก้โค้ด แก้ผ่าน `/admin` ได้ทั้งหมด

| จุดที่ใส่รูปได้ | แก้ที่ | ขนาดที่แนะนำ |
|---|---|---|
| โลโก้งาน (หัวเว็บทุกหน้า) | `/admin/settings` → รูปภาพประจำงาน | จัตุรัส 200×200 px พื้นหลังโปร่ง |
| ภาพพื้นหลังหน้าแรก (ฮีโร่) | `/admin/settings` → รูปภาพประจำงาน | แนวนอน 1920×1080 px |
| โลโก้ทีม | `/admin/teams` → ช่อง “ลิงก์โลโก้” | จัตุรัส 300×300 px |
| ภาพปกข่าว | `/admin/news` → ช่อง “ลิงก์ภาพปก” | แนวนอน 1200×630 px |
| โลโก้ผู้จัด/ผู้สนับสนุน | `/admin/sponsors` → ช่อง “ลิงก์โลโก้” | จัตุรัส 200×200 px |
| อัลบั้มภาพบรรยากาศ | `/admin/gallery` → ช่อง “ลิงก์ภาพ” | แนวนอน ไม่จำกัด |
| ไอคอนแท็บเบราว์เซอร์ | ไฟล์ `public/icon.svg` | แก้ไฟล์แล้ว deploy ใหม่ |
| ภาพตอนแชร์ลิงก์ (OG image) | ไฟล์ `app/opengraph-image.tsx` | 1200×630 px สร้างอัตโนมัติ |

### วิธีอัปโหลดรูปเพื่อเอาลิงก์มาใช้

ใช้ **Supabase Storage** ได้เลย ไม่ต้องหาที่ฝากรูปที่อื่น

1. Supabase → **Storage** → **New bucket** ตั้งชื่อ `media` และติ๊ก **Public bucket**
2. กด **Upload file** อัปโหลดรูปเข้าไป
3. คลิกที่ไฟล์ → **Copy URL** แล้วนำลิงก์ไปวางในช่องที่ต้องการใน `/admin`

หรือจะวางไฟล์ไว้ในโฟลเดอร์ `public/` ของโปรเจกต์แล้วอ้างเป็น `/ชื่อไฟล์.jpg` ก็ได้
(ไฟล์ `public/hero.jpg` คือแบนเนอร์งานที่มีอยู่เดิม)
